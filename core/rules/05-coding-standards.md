# Rule: Coding Standards & Conventions

- **Summary Comments Structure**: Always follow existing XML summary documentation comment structures (`<summary>`, `<param>`, `<returns>`, `<exception>`) matching adjacent repository files.
- **No Unused Usings**: Keep source files clean and free of dead or unused `using` directives.
- **Folder Conventions**: Strict adherence to the project structure (`src/IdempotencyEngine.{Domain,Data,Api}/`, subfolders under services for domain/entity grouping, and `migrations/` for SQL).
